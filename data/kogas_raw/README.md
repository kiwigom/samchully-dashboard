# KOGAS 용도별 도매요금표 CSV 폴더

GitHub Actions(정기 자동 수집)에서 도시가스 산업용요금을 계산하려면, KOGAS에서
다운로드한 원본 CSV 파일들을 이 폴더에 커밋해 두어야 합니다. (GitHub Actions는
리눅스 서버에서 실행되므로 내 PC의 "C:\Users\student\Desktop\삼천리 프로젝트\천연가스가격"
폴더에는 접근할 수 없습니다.)

로컬(내 PC)에서 앱을 직접 실행할 때는 이 폴더 대신 기존 데스크탑 폴더를 계속 써도 됩니다
(config.py가 두 위치를 자동으로 구분해서 사용합니다).
